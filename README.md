# LeiloesTDSat

## Sobre o projeto

O LeiloesTDSat é um projeto desktop desenvolvido para apoiar as atividades de uma casa de leilões. A proposta é organizar informações dos produtos que são cadastrados para participar dos leilões, permitindo consultar dados como nome, valor e situação do item.

O projeto contém telas para cadastrar produtos e consultar a listagem de produtos. Ele está em desenvolvimento e poderá receber novas funcionalidades ao longo das próximas etapas.

## Tecnologias utilizadas

- Java
- Java Swing (interface gráfica)
- MySQL/MariaDB (banco de dados)
- JDBC (conexão entre a aplicação Java e o banco de dados)
- Apache Ant (construção do projeto)
- NetBeans IDE

## Banco de dados

O arquivo `uc11.sql` disponibilizado com o projeto contém a estrutura e alguns registros iniciais da tabela `produtos`. Antes de executar a aplicação, importe esse arquivo em um banco chamado `uc11`.
